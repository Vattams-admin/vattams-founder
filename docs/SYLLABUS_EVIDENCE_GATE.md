# Syllabus Evidence Gate

VATTAMS Academia must not infer a board syllabus from another board, an old curriculum, a generic textbook, or an unverified web page.

Every production curriculum/exam track must have an evidence record before authoring can become curriculum-aligned.

Required evidence:
- official source type
- source title and locator
- curriculum/syllabus version
- effective date
- retrieval timestamp
- content hash
- verification identity and timestamp
- explicit approval status

Lifecycle:

Missing → Collected → Verified → Approved → Superseded

Only **Approved** evidence can authorize production authoring. Superseded evidence cannot authorize new content.

Third-party material can support research but cannot replace the authoritative curriculum source.

Translations must remain tied to the exact approved source version. A translation never changes the underlying curriculum scope.

This gate is intentionally separate from content quality review: syllabus alignment proves *what should be taught*; content review proves *whether the authored material is correct and high quality*.

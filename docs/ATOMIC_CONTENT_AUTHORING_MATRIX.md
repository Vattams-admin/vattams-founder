# Atomic Content Authoring Matrix

This is the production queue contract for VATTAMS Academia.

## School

The authoring universe is Class 1 through Class 12.

### National
- CBSE
- ICSE
- ISC
- NIOS

### State / UT
- State / UT Board, separately for every jurisdiction in the India Education Registry
- Matriculation / state-specific private curricula only where official curriculum evidence exists

### International
- IB
- Cambridge International
- Pearson Edexcel

A school package is not considered complete merely because notes exist. The atomic package progresses through:

Curriculum Map → Subject Map → Chapter Map → Lesson Notes → Concepts/Definitions → Worked Examples → Appropriate Visuals → Basic Practice → Conceptual Practice → Application Practice → HOTS → Common Mistakes → Key Takeaways → Flash Recall → Formula/Fact Bank → Chapter Revision → Weak-Topic Revision → Chapter Test → Subject Test → Mock Test → Official Attempt.

## Question bank

Every production MCQ must carry a complete locator and governance record.

Required:
- unique question ID
- curriculum/class/exam locator
- subject/chapter/topic/subtopic
- question type
- difficulty
- language
- age band where applicable
- exactly four unique options
- private correct option
- detailed reasoning
- marks
- expected time
- provenance
- version
- review status

## Runtime

Practice can reveal the correct answer and reasoning after submission.

Official attempts expose only the question and four options during the attempt. The answer key and explanation remain private.

Question selection applies curriculum and eligibility before age adaptation, then uses blueprint/difficulty/topic controls, repetition avoidance and student-specific ordering. Options are randomized.

## India-wide language model

The language registry is the source of truth. A translation is its own version and must pass language review. Machine translation cannot publish automatically.

## Exam packages

Competitive, entrance and professional packages use the same atomic pattern:

Syllabus → Study Material → Topic/Lesson → Practice → Sectional → PYQ when authorized → Mock → Revision → Weak Topic → Official Attempt → Results.

Professional education explicitly includes CA, CMA, CS and Audit & Assurance, plus extensible professional qualification tracks.

## Competitions

Thirukkural Mastery Championship is the reference runtime.

Competition package:

Eligibility → Study Materials → Topic Learning → Practice → Mock → Revision → Age Group Pool → Official Attempt → Results → Certificate.

## Governance

Draft → Automated Validation → Quality Review → CEO Approval → Published → Retired.

CEO approval is auditable and can be configured for automatic execution only after mandatory gates pass. It never means bypassing quality, security, provenance or answer-key controls.

This matrix is an authoring target. It does not claim that uncreated content exists.

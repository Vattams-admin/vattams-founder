# VATTAMS Academia — Assessment Blueprint Authoring Workbench

This layer records explicit, human-authored assessment quotas without fabricating them.

Required inputs: exact question count, section counts, topic counts, difficulty distribution, eligibility policy, source evidence, author identity, and review decision.

Lifecycle: draft → in_review → approved.

Approval is separate from structural validation and question-bank coverage. An approved blueprint still cannot become executable until the real reviewed question inventory satisfies the coverage engine.

Incomplete official evidence must remain blocked; the workbench never infers missing quotas.

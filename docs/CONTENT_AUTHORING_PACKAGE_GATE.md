# Content Authoring Package Gate

A production authoring package is the atomic handoff from an evidence-backed curriculum to actual educational content.

## Required layers

Study material:
- objectives
- concepts
- definitions
- worked examples
- common mistakes
- key takeaways
- revision points

Practice:
- basic
- conceptual
- application
- higher-order thinking
- mixed review

Revision:
- quick revision
- flash recall
- formula/fact bank
- mistake-based revision
- weak-topic revision

## Question security

Every MCQ has exactly four unique options. Public question data contains no correct answer or explanation. Private answer keys contain the verified correct option and reasoning.

The gate rejects duplicate questions, duplicate options, missing keys and orphan keys. It also rejects any authoring package created while curriculum authoring readiness is locked.

No package is published by this gate. Review, provenance, hashing, CEO approval and publication remain separate governance stages.

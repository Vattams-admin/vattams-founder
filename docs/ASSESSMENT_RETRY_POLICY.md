# Assessment Retry Policy

Retry eligibility is server-authoritative. The client cannot request an unlimited new attempt.

- Practice assessments: unlimited by default.
- Mock tests: up to 3 submitted attempts by default.
- Official attempts: one submitted attempt by default.
- An existing in-progress attempt must be resumed rather than creating another attempt.

A future assessment-specific override may tighten these limits, but cannot weaken official-attempt safety without explicit governance.

# VATTAMS Academia — Syllabus Artifact Integrity Gate

The syllabus evidence gate requires a real source artifact, not merely a URL.

## Required integrity record

Every captured syllabus artifact records:

- source type
- official source title
- source locator
- retrieval timestamp
- SHA-256 digest of the captured artifact
- lifecycle status
- replacement relationship when superseded

## Lifecycle

captured → verified → approved → content authoring

A URL alone never satisfies the integrity requirement.

## Security and governance

- SHA-256 must be exactly 64 hexadecimal characters.
- Placeholder or invented hashes are rejected.
- An official URL does not automatically mean the artifact is approved.
- Verification and approval remain separate governance decisions.
- Superseded artifacts cannot authorize new content.
- The artifact registry does not download or fabricate source documents; it records the integrity metadata of an artifact captured through an approved evidence process.
